# Editor Electron

Editor de GBA Studio baseado em Electron, React e TypeScript.

Execute os comandos deste pacote neste diretório:

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

Para configurar o motor, exportar ROMs e executar Play, consulte o
[guia de desenvolvimento](../../docs/development.md).
O [README principal](../../README.md) descreve a organização do monorepo,
contribuições e licenças.

# Insumos de regressão dos assets

Este diretório contém metadados e cópias exatas de recursos originais aprovados
usados por testes existentes. Os registros de runtime e preparação preservam
os hashes; os três sprites point-and-click e as três composições de HUD
preservam os bytes de suas fontes.

As fontes de produção, propostas não aprovadas e arquivos de conversa não são
necessários para executar esses testes e não acompanham o repositório público.
A licença dos recursos originais é MIT, conforme ASSET_LICENSES.md.

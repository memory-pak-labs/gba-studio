# Insumos de regressão dos assets

Este diretório contém metadados e cópias exatas de recursos originais aprovados
usados pelos testes existentes. `approved-inputs.json` registra a origem
histórica e o SHA-256 de cada PNG. Nenhum pixel foi alterado para publicação.

Os testes de promoção usam os insumos de abertura, usina, Arena V5, sprites,
marcadores táticos e HUDs. As versões anteriores dos sprites da Arena V5
permitem verificar que apenas os frames de dano aprovados mudaram. Arquivos
complementares de paleta, animação e composição permitem reproduzir os testes.

Os lotes de produção, propostas não aprovadas e arquivos de conversa não são
necessários para executar esses testes e não acompanham o repositório público.
A licença dos recursos originais é MIT, conforme ASSET_LICENSES.md.

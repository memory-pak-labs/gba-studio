# Exported Battle RPG

Runtime nativo de batalha RPG. Esquerda/Direita selecionam o alvo, A ataca e B tenta fugir.

Compila fora do repositório com headers públicos, `lib/libgbastudio_engine.a`, `templates/gba.ld`, `templates/Makefile.gba`, `tools/gbsdoctor` e `tools/gbsbuild`, sem depender do Butano.
